==================================================
KEYBOARD TYPING-MASTER
==================================================

**Keyboard Typing-Master** — это инструмент для анализа и сравнения эффективности различных раскладок клавиатуры при десятипальцевом методе печати.

Проект разработан для исследователей, разработчиков и энтузиастов, стремящихся оценить эргономику раскладок на основе реальных текстов и статистических метрик.

---

📌 Цель проекта
===============

Цель — определить наиболее удобную и сбалансированную раскладку клавиатуры для русскоязычного набора текста.  
Анализ проводится по трём раскладкам:

- **ЙЦУКЕН** — стандартная русская раскладка  
- **Вызов** — экспериментальная раскладка  
- **Зубачев** — альтернативная оптимизированная раскладка

Каждая раскладка оценивается по степени физической нагрузки, которую испытывают пальцы при наборе текста.  
Моделируются движения пальцев: вверх, вниз, влево, вправо и по диагонали. За каждое движение начисляется штраф:

- Простое перемещение — 1 балл  
- Диагональное или двойное — 2, 3 или 4 балла (например, для букв `х`, `ъ` и других неудобных позиций)

Анализ проводится на основе следующих источников:

- Текст «Война и мир» (без иностранных символов)  
- Список русских лексем  
- Частотный файл диграмм (`sortbukw.csv`, ~647 строк)

Результаты визуализируются в виде графиков, отражающих нагрузку на каждый палец и общую нагрузку по раскладкам.

---

🧩 Структура проекта
====================

Проект состоит из трёх основных модулей:

1. **Сбор и обработка данных**  
   Подготовка текстового корпуса, фильтрация символов, извлечение лексем и частот

2. **Анализ раскладок**  
   Моделирование движений пальцев, расчёт штрафов, распределение нагрузки

3. **Визуализация результатов**  
   Построение графиков, сравнительный анализ, вывод итогов

---

📈 Методика оценки
==================

Каждое движение пальца при наборе текста классифицируется по направлению и расстоянию.  
Система штрафов учитывает:

- Простые перемещения (1 балл)  
- Сложные перемещения — диагонали, двойные шаги (2–4 балла)

Оценка проводится с учётом частоты букв, чередования рук, средней длины слов и других метрик.  
Итоговая нагрузка отображается графически — по каждому пальцу и в целом по раскладке.
