# 🧠 Keyboard Typing-Master

![Статус проекта](https://img.shields.io/badge/status-active-blue)
![Python](https://img.shields.io/badge/python-3.8%2B-green)
![GUI](https://img.shields.io/badge/interface-PyQt5-orange)
![Coverage](https://img.shields.io/badge/test--coverage-100%25-brightgreen)

Инструмент для анализа и визуального сравнения эффективности различных раскладок клавиатуры при десятипальцевом методе печати.  
Проект моделирует движения пальцев, рассчитывает нагрузку и визуализирует результаты на основе реальных текстов.

## 🧪 Тестирование

Модульное тестирование выполнено с помощью [pytest](https://docs.pytest.org/).  
Каждая функция проверяется на **7 различных раскладках клавиатуры**, включая `standard`, `challenge`, `zubachev` и другие.

- ✅ **Всего выполнено**: 58 тестов  
- 🧩 **Охват**: анализ текста, распределение нагрузки, визуализация  

### 📦 Команда для запуска

```bash
python -m pytest test.py -v
```````

```text

test_analyze_text[vyzov] PASSED
...
=========================== 58 passed in 1.23s ============================
```````

## 📈 Сравнительный анализ

### ⚖️ Нагрузка на руку

На основе тестов («Война и мир», «Сортировка букв», «Минимальные фразы») можно выделить общие тенденции:

#### ⚡ Самые удобные раскладки

- **Вызов**  
  - Минимальное количество нажатий (экономия ~8–25% по сравнению со стандартом).  
  - Короткий средний путь пальцев (0.30–0.66).  
  - Хороший баланс нагрузки между руками.  
  - **Итог:** самая эргономичная раскладка, снижает утомляемость и ускоряет набор.

- **Зубачев**  
  - Схожие показатели с «Вызовом», чуть больше путь пальцев.  
  - Экономия нажатий ~10–20% относительно стандарта.  
  - **Итог:** удобная и сбалансированная альтернатива.

- **Скоропись**  
  - Средние показатели: нажатий меньше, чем у стандарта, но путь пальцев выше, чем у «Вызова».  
  - **Итог:** компромисс между скоростью и привычностью.

#### ⚖️ Средние по удобству
- **Диктор**  
  - Нажатий почти как у стандарта, но путь пальцев чуть короче.  
  - **Итог:** умеренное улучшение без радикальных преимуществ.

- **Ант**  
  - Нажатий меньше, но общий путь пальцев выше.  
  - **Итог:** баланс не оптимален, но лучше стандарта.

#### 🛑 Наименее удобные
- **Стандарт**  
  - Базовый уровень: много нажатий, длинный путь пальцев.  
  - **Итог:** устаревший вариант, сильно уступает альтернативам.

- **Русфон**  
  - Самый длинный путь пальцев (до 1.19), нагрузка почти полностью на правую руку.  
  - **Итог:** худший результат по эргономике.

### 🥇 Лучшая раскладка
**Русфон** — наиболее сбалансированная: выигрывает по удобству комбинаций, остаётся приемлемой в длинных текстах.

### 🥉 Худшая раскладка
**Зубачев** — несмотря на экономию движений в текстах, в комбинациях показал наихудшие результаты (до 93% неудобных).  
**Вызов** близок к нему: быстрый, но неудобный для сочетаний.
